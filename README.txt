================================================================================
 Offline PDF Editor – Windows App
================================================================================

এটা একটা সম্পূর্ণ Offline PDF Editor।
ডাবল-ক্লিক করলেই GUI ইন্টারফেস খুলবে।
Python ইনস্টল করার দরকার নেই (যখন .exe বানিয়ে নেবেন)।

FEATURES
--------
- PDF খোলা ও দেখা
- টেক্সট সার্চ (Ctrl+F)
- বিদ্যমান টেক্সট এডিট করা
- হাতের লেখা সিগনেচার যোগ করা
- Save / Save As
- Undo (Ctrl+Z)
- সম্পূর্ণ Offline – ইন্টারনেট লাগে না

--------------------------------------------------------------------------------
কীভাবে Windows .exe পাবেন (Python ছাড়া) – GitHub Actions
--------------------------------------------------------------------------------

১. GitHub-এ নতুন Public Repository বানান (নাম: OfflinePDFEditor)

২. এই ফোল্ডারের সব ফাইল সেই Repository-তে আপলোড করুন

৩. Repository-তে গিয়ে "Actions" ট্যাবে ক্লিক করুন

৪. বাম পাশে "Build Windows EXE" সিলেক্ট করুন

৫. ডান পাশে "Run workflow" বাটনে চাপুন → আবার "Run workflow"

৬. ৮–১৫ মিনিট অপেক্ষা করুন

৭. সবুজ টিক চিহ্ন দেখলে ক্লিক করুন → নিচে Artifacts সেকশনে
   "OfflinePDFEditor-Windows" ডাউনলোড করুন

৮. ZIP খুলে OfflinePDFEditor.exe পাবেন
   সেটা যেকোনো Windows পিসিতে কপি করে চালাতে পারবেন।
