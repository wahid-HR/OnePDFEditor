============================================================
  Offline PDF Editor – সহজ বাংলা গাইড (GitHub দিয়ে .exe বানানো)
============================================================

আপনার পিসিতে Python ইনস্টল করতে হবে না।
GitHub বিনামূল্যে .exe বানিয়ে দেবে।

------------------------------------------------------------
ধাপ ১: GitHub-এ নতুন Repository বানান
------------------------------------------------------------
1. https://github.com এ লগইন করুন
2. উপরের ডানদিকে "+" চাপুন → "New repository"
3. Repository name লিখুন: OfflinePDFEditor
4. Public সিলেক্ট করুন (খুব জরুরি)
5. "Create repository" চাপুন

------------------------------------------------------------
ধাপ ২: ফাইল আপলোড করুন
------------------------------------------------------------
1. নতুন Repository পেজে "uploading an existing file" লিংকে ক্লিক করুন
   অথবা
   "Add file" → "Upload files"
2. আপনার কম্পিউটার থেকে OfflinePDFEditor ফোল্ডারের ভিতরের
   সব ফাইল ও ফোল্ডার সিলেক্ট করে ড্র্যাগ করে ছেড়ে দিন
   (app ফোল্ডার, .github ফোল্ডার, requirements.txt ইত্যাদি সব)
3. নিচে "Commit changes" বাটনে চাপুন

------------------------------------------------------------
ধাপ ৩: .exe বানানো শুরু করুন
------------------------------------------------------------
1. Repository-তে উপরের মেনু থেকে "Actions" ট্যাবে যান
2. বাম পাশে "Build Windows EXE" নামের workflow দেখবেন
3. ডান পাশে "Run workflow" বাটনে ক্লিক করুন
4. আবার "Run workflow" চাপুন
5. ৮ থেকে ১৫ মিনিট অপেক্ষা করুন

------------------------------------------------------------
ধাপ ৪: .exe ডাউনলোড করুন
------------------------------------------------------------
1. বিল্ড শেষ হলে সবুজ টিক (✓) দেখাবে
2. সেই রানে ক্লিক করুন
3. নিচে "Artifacts" সেকশনে যাবেন
4. "OfflinePDFEditor-Windows" নামে একটা আইটেম দেখবেন
5. সেখানে ক্লিক করে ডাউনলোড করুন
6. ZIP ফাইল খুললে ভিতরে OfflinePDFEditor.exe পাবেন

------------------------------------------------------------
ধাপ ৫: ব্যবহার করুন
------------------------------------------------------------
OfflinePDFEditor.exe ফাইলটাকে যেকোনো জায়গায় কপি করে
ডাবল-ক্লিক করুন। অ্যাপ্লিকেশন খুলে যাবে।

এই .exe ফাইল অন্য যেকোনো Windows পিসিতেও চলবে।
Python বা অন্য কিছু ইনস্টল করার দরকার নেই।

============================================================
সমস্যা হলে
============================================================
- Actions ট্যাবে গিয়ে লাল ক্রস দেখলে → সেখানে ক্লিক করে
  লগ দেখুন এবং আমাকে বলুন।
- Artifact না পেলে → workflow সঠিকভাবে শেষ হয়েছে কিনা চেক করুন।

শুভকামনা!
