NOTES ON LIMITATIONS
--------------------
1. Complex-script support (Bengali, Arabic, CJK, etc.) requires either
   system fonts that cover those ranges or shipping additional font files
   (e.g. Noto Sans). The current offline package deliberately stays small
   and uses only PDF Base-14 fonts for maximum portability.
2. PDF text editing can never be 100 % perfect for every possible PDF
   structure. Overlapping text, unusual encodings, Form XObjects, or
   heavily subsetted fonts may produce imperfect visual results. The
   application never claims Acrobat-level compatibility.
3. The Windows executable must be built on a Windows machine (or a
   Windows CI runner) using BUILD_WINDOWS.bat. The Linux environment
   used for this report cannot produce a native Windows .exe.

HOW TO BUILD THE WINDOWS EXECUTABLE
-----------------------------------
See README.txt and run BUILD_WINDOWS.bat on a Windows host with Python 3.8+.
